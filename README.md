## 🔑 什么是强弱COM？

**COM = Committee（招生委员会）**

| 类型 | 主导方 | 核心特点 |
|---|---|---|
| 🔴 强COM | 学院招生办 | 统一笔试+面试，按综合排名录取，导师无单独录取权 |
| 🔵 弱COM | 导师 | 招生名额下放到导师/课题组，提前套磁是关键 |
| 🟠 强弱混合 | 因院系/方向而异 | 同一学校不同院系COM属性可能不同 |

> 💡 **强COM** 适合本科背景好、绩点排名高、应试能力强的同学；  
> 💡 **弱COM** 适合绩点一般但科研/竞赛突出，或能打动特定导师的同学。
